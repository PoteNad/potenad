# Security Policy

Only the latest release of PoteNad receives security updates.

## Reporting a Vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/PoteNad/potenad/security/advisories/new) instead of opening a public issue.

Include a description of the issue, steps to reproduce it, its potential impact, and the affected PoteNad and macOS versions. Reports will be reviewed as soon as possible.
